# concept-explainer · 抽象概念多角度讲解助手

> 把"一听就懵"的抽象概念（死锁、递归、事务隔离级别、闭包、熵……），拆成四个互相呼应的视角讲透，并渲染成一份**自包含、可直接预览**的浅色学术风 HTML 卡片。

适用于**备课、一对一辅导、自学**，覆盖 **CS / 数学 / 物理 / 通用** 领域。

---

## 一、它解决什么问题

抽象概念难讲，往往不是因为"太难"，而是因为只给了一个角度。本 skill 强制从四个互补视角切入，让不同基础的学生都能找到入口：

| 角度 | 作用 | 写法要点 |
|------|------|----------|
| **生活类比** | 把抽象映射到具体 | 1–2 段日常场景；末尾点明"现象 ↔ 概念要素"的对应，并补一句"类比边界"防过度延伸 |
| **示意图描述** | 让脑补有骨架 | ASCII / 流程 / 状态图；写清元素个数、箭头方向、标注文字 |
| **最小可运行代码** | 跑一遍就懂 | 自包含、可复制、含入口；附"运行预期"+"哪行对应概念哪点" |
| **学生常见误解** | 排雷 | 3–5 条，格式 `误解：… → 正解：…`，优先来自真实教学反馈 |

四个角度**彼此呼应**：同一套比喻、同一段代码贯穿全卡，而不是零散四块。

---

## 二、亮点：难度 × 受众 双筛选

这是本 skill 区别于普通"讲概念"提示词的核心设计。两个维度贯穿全部四角度，且**在生成期和最终 HTML 交互上双重生效**：

| 维度 | 取值 | 作用方式 |
|------|------|----------|
| **受众** | 中学生 / 大学生 / 自学者 / 教师 | 生成期决定语气与术语；HTML 中用 `.callout[data-aud]` 给该受众专属提示，可点击切换显隐 |
| **难度** | 易 / 中 / 难 | 基础内容全难度可见；进阶内容包进 `.adv[data-depth="1"|"2"]`（1=中、2=难），HTML 顶部按钮按难度显隐 |

- **受众=中学生**：纯生活比喻、零术语，可省略代码，误解聚焦"字面直觉错"。
- **受众=大学生/自学者**：给最小可运行代码，误解聚焦"概念混淆 / 工程卡点"。
- **受众=教师**：额外给"讲授引入话术 / 提问预设"。
- 未指定时默认 **受众=大学生、难度=中**。

---

## 三、工作流程（4 步）

1. **解析概念、学科与筛选维度**——判断学科范式（编程/数学/物理/通用）以选语气与代码语言；解析受众/难度（未指定用默认）。
2. **四角度生成（核心）**——强制产出生活类比 / 示意图描述 / 最小可运行代码 / 学生常见误解，且四块呼应。
3. **先输出 Markdown 版**——顶部加元信息行 `概念：X ｜ 学科：Y ｜ 受众：Z ｜ 难度：W`，便于核对与复制。
4. **渲染可筛选 HTML 卡片（默认）**——基于内置模板生成自包含 HTML，接好受众/难度筛选开关；浏览器直接打开即可投屏或自学。

> 若用户明确只要 Markdown、不要网页，则跳过第 4 步。

## 四、文件结构

```
concept-explainer/
├── SKILL.md                       # 触发词、四角度范式、难度×受众矩阵、4 步流程
├── references/
│   └── concept-patterns.md        # 分学科讲解范式 + 难度×受众矩阵 + 3 套已验证示例
└── assets/
    └── concept-card-template.html # 自包含卡片模板（内置筛选 JS/CSS，无外部依赖）
```

**自包含、无外部 Skill 依赖**：讲解与渲染完全由本 skill 的内置 references + HTML 模板 + LLM 生成完成，不调用其他 skill。

## 五、已验证示例（开箱即用模板）

`references/concept-patterns.md` 内置三套经过校验的范例，作为保真模板：

| 概念 | 学科 | 一句话类比 |
|------|------|------------|
| **死锁** | 编程 | 两人各拿一只筷子互等对方放下，谁都不松手就永远吃不上 |
| **递归** | 编程 | 俄罗斯套娃，打开最小的空娃（基线）才开始一层层合上 |
| **事务隔离级别** | 数据库 | 自习室里你能看到别人改到一半的笔记到什么程度 |

每套示例都完整给出四角度内容，新增概念时优先对齐其结构与语气。

## 六、怎么用

直接在 WorkBuddy 中调用：

```
@concept-explainer 讲讲死锁
@concept-explainer 用通俗的话解释递归，受众=中学生，难度=易
@concept-explainer 把熵讲给高中生听
@concept-explainer 做个概念讲解卡片：闭包，难度=中，受众=自学者
```

触发词示例：「讲讲 X」「用通俗的话解释 X」「X 怎么教」「把 X 讲给 Y 听」「做个概念讲解卡片」。

## 七、输出物说明

- **Markdown 版**：四段式，便于快速核对与复制到笔记/课件。
- **HTML 卡片版**（默认）：
  - 浅色学术风 + 思源宋体，中文显示正常；
  - 受众 / 难度筛选按钮，点击即时显隐对应内容；
  - 单文件、无外部依赖，可直接浏览器打开、课堂投屏或分享。

---

## 八、注意事项

- **只要文字不要网页**：明确说明"只要 Markdown"，则跳过 HTML 渲染步骤。
- **代码自包含**：最小可运行代码示例复制即可运行并看到现象，不适合代码的概念（纯数学/物理）改为"最小计算示例 + 关键公式"。
- **维度默认值**：未指定受众/难度时，按 大学生 / 中 生成，可在生成后要求调整。
- **类比边界**：生活类比用于建立直觉，需在卡片中点明"对应哪个概念要素"及"类比的边界"，避免过度延伸误导。

---

## 九、适用与不擅长

- ✅ 适合：需要"多角度、通俗、配图、配代码、面向特定学生群体"讲解的抽象概念。
- ⚠️ 不擅长：需要实时联网查最新资料、需要精确论文引用、或纯工程调试类任务（请用更专门的 skill）。
